# 当前状态 v1

## 当前定位

`toptrader-research` 是训练剧本、能力包和知识路由资料库。它不是应用运行入口，也不是交易数据源。

应用运行和 Agent 写入看：

- `../../README.md`
- `../../TOPTRADER_SKILL_USAGE.md`
- `../../app/README.md`

## 当前最有用的文件

- `00-index/knowledge-router-v1.md`
- `00-index/master-index.md`
- `00-index/source-map-v1.md`
- `06-workflows/*.md`
- `08-reading-path/*.md`

## 使用方式

- Agent 通过 `00-index/knowledge-router-v1.md` 找到最相关的 playbook 或能力包。
- 用户日常不需要手动浏览完整资料库。
- 新增剧本或能力包后，要同步更新知识路由索引。

## 当前不做

- 不把研究资料全量搬到前端。
- 不让知识路由替代交易规则。
- 不把疑似失真直接定性为最终结论。
