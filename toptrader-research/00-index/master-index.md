# 总索引 — 顶级交易员研究

## 当前定位

本目录保存 Agent 可调用的交易行为改进资料。它不追求完整研究书架，优先服务当前 TrendGo 的纪律、复盘和能力训练。

应用入口在：

- `../../README.md`
- `../../TOPTRADER_SKILL_USAGE.md`
- `../../app/README.md`

## 当前核心索引

- `knowledge-router-v1.md`：Agent 情境路由，当前最重要。
- `master-dashboard-v1.md`：资料总览。
- `source-map-v1.md`：研究来源地图。
- `current-status-v1.md`：当前状态。
- `system-usage-flow-v1.md`：如何使用资料库。
- `collection-protocol.md`：后续资料收集标准。

## 当前资料区

- `../06-workflows/`：即时问题 playbook。
- `../08-reading-path/`：长期能力包。

## 使用原则

- 日常交易不从这里录入，交易数据进入 TrendGo。
- Agent 每次只调用一个最相关 playbook 或能力包。
- 研究资料不能覆盖风控硬规则。
- 新增资料要能转成具体行为，不做纯收藏。
