# 顶级交易员研究收集规范

## 目标

围绕一个问题建立高质量研究基础：

**成为顶级交易员到底需要什么？**

## 收集类别

1. 书籍 / 电子书
2. 学术论文
3. 访谈 / 演讲 / 播客
4. 传记 / 案例研究
5. 心理学 / 训练 / 刻意练习
6. 真实交易工作流和操作系统

## 来源标准

优先选择这些来源：
- 第一手或接近第一手
- 来自真实顶级交易员或可信研究者
- 过程信息丰富，而不只是结果
- 能提炼出原则和行动

降低优先级的来源：
- 泛泛的励志内容
- 低信息量金融内容
- 营销漏斗
- 卖信号或大师包装内容

## 需要记录的元数据

对每个条目尽量记录：
- 标题
- 创作者 / 作者 / 讲者
- 来源类型
- 链接或引用
- 主要主题
- 为什么重要
- 优先级：高 / 中 / 低
- 可行动性：高 / 中 / 低
- 摘要状态：无 / 待处理 / 已完成

## 研究阶段

### 第 1 阶段 — 建立广泛资料地图
重点是覆盖面。

### 第 2 阶段 — 筛选最高价值材料
重点是信号质量。

### 第 3 阶段 — 总结和综合
重点是提炼原则。

### 第 4 阶段 — 转化为 Joe 爸的成长路径
重点是练习，而不只是知识。

## 文件卫生

- 每个主题放在自己的文件夹或文件中
- 不要把项目管理文件和研究文件混在一起
- 优先使用可追加的 Markdown 索引，而不是零散笔记
