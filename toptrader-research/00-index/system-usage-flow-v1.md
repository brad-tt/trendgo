# 系统使用流程 v1

## 当前定位

本资料库用于给 Agent 提供训练剧本和能力包，不是日常应用入口。日常记录和复盘看 TrendGo Skill。

## 日常使用

1. 用户在 TrendGo Skill 或前端里记录交易、纪律事件和复盘。
2. Agent 根据用户当前问题读取 `knowledge-router-v1.md`。
3. Agent 只推送一个最相关的 playbook 或能力包。
4. 复盘时把建议落到下一次可执行动作。

## 即时问题

当出现冲动、报复、犹豫、亏损后失控、盈利后过度自信等情况时：

- 先看 `knowledge-router-v1.md` 选择路由。
- 再进入 `../06-workflows/` 下对应 playbook。
- 只执行一个降风险动作。

## 长期成长

每周只选一个能力包：

- `../08-reading-path/execution-discipline-pack-v1.md`
- `../08-reading-path/emotional-control-pack-v1.md`
- `../08-reading-path/risk-management-pack-v1.md`
- `../08-reading-path/market-understanding-pack-v1.md`
- `../08-reading-path/review-and-learning-pack-v1.md`

## 主要规则

不要把这个系统当作阅读档案。它只服务于交易行为改进。
