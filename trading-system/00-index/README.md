# 交易系统总纲

## 目标

辅助 Joe 爸从主观、情绪化、易犯错的短线交易，进化为有框架、有纪律、有复盘闭环的交易员。

## 当前定位

`trading-system` 是规则和交易判断资料库，不是应用运行入口，也不是交易数据源。

日常记录和复盘进入 TrendGo：

- `../../README.md`
- `../../TOPTRADER_SKILL_USAGE.md`
- `../../app/README.md`

## 当前保留目录

- `00-index/`：总纲、作战中枢、规则索引和导航。
- `04-risk-control/`：硬规则、软规则、停手条件。
- `05-setups/`：A/B/C 级机会、交易前检查清单、美股期权评分。

## 核心原则

1. 先活下来，再做大。
2. 先控制回撤，再追求暴利。
3. 交易靠系统，不靠感觉。
4. 稳定执行比偶尔神单更重要。
5. 复盘要落到具体问题，而不是情绪总结。
6. 没有真实交易记录，就没有系统优化。
7. 任何观点都不能覆盖风控硬规则。
