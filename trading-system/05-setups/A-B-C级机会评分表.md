# A/B/C 级机会评分表（初版）

## 结论
机会分级不能靠感觉，至少要用几个维度打分。

## 评分维度
每项 0-2 分：
1. 方向是否清晰
2. 位置是否合理
3. 是否有确认信号
4. 止损是否清楚
5. 盈亏比是否划算
6. 自己当前状态是否稳定

## 一票降级
出现以下任一情况，直接降为 C 级，不再打分：
- 止损说不清
- 只是怕错过
- 连亏后想翻本
- 情绪明显不稳
- 方向、位置、确认三项里有两项说不清

## 判定
- **10-12 分**：A 级机会
- **7-9 分**：B 级机会
- **6 分及以下**：C 级机会

## 仓位绑定
- A 级：允许正常仓位，但必须有止损
- B 级：只允许小仓试错
- C 级：不做
- 连亏或情绪不稳时，所有机会自动降一级

## 原则
- 低分机会不靠主观自信升级
- 状态差时，即使行情好，也要降级
