# 美股期权 A-B-C 级机会评分表（V1）

## 评分维度
每项 0-2 分，总分 14 分：

1. 正股方向是否清晰
2. 位置是否在关键位附近
3. 是否有明确确认信号
4. 合约流动性是否合格
5. 止损权利金是否清楚
6. 计划盈亏比是否划算
7. 当前状态是否稳定

## 一票降级
出现以下任一情况，直接降为 C 级：

- 没有止损权利金
- 只是怕错过
- 财报或重大消息前后赌方向
- 合约点差明显过大
- 连亏后想翻本
- 情绪明显不稳
- 正股方向、位置、确认三项里有两项说不清

## 判定
- **10-14 分**：A 级机会
- **7-9 分**：B 级机会
- **6 分及以下**：C 级机会

## 仓位绑定
- A 级：允许正常张数，但必须先定止损权利金。
- B 级：只允许小张数试错。
- C 级：不做。
- 连亏或情绪不稳时，所有机会自动降一级。

## 原则
期权会放大情绪和亏损速度，所以低分机会不允许用“感觉”升级。
